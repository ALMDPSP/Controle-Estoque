CONTROLE DE ESTOQUE — ENTRADA E SAÍDA DE EQUIPAMENTO
======================================================

O que é:
Um programa em Python (Flask) com página web, para cadastrar itens:

  - Código do item        - NF de entrada
  - Descrição              - Data de entrada
  - Qtde                   - NF de saída
  - Localização             - Data de saída
  - VD da loja que vai receber o item

Agora o programa tem:
  - LOGIN por usuário e senha (cada pessoa com o seu)
  - Banco de dados de verdade (não é mais um arquivo Excel solto —
    isso é o que permite hospedar na internet sem perder dados)
  - Botão "Exportar para Excel" a qualquer momento, que baixa um
    .xlsx com tudo o que está cadastrado
  - Pronto para subir no GitHub e publicar no Render

ESTRUTURA DOS ARQUIVOS
------------------------------------------------------------------
app.py                -> o programa principal (rotas, login, API)
db.py                  -> acesso ao banco de dados (SQLite local / Postgres no Render)
templates/login.html   -> tela de login
templates/index.html   -> tela principal (cadastro e lista de itens)
templates/usuarios.html-> gestão de usuários (só admin)
requirements.txt       -> bibliotecas necessárias
Procfile               -> comando que o Render usa para iniciar o programa
render.yaml             -> modelo de configuração para deploy automático (opcional)
.gitignore              -> arquivos que não devem ir para o GitHub
