ESTRUTURA DOS ARQUIVOS
------------------------------------------------------------------
app.py                -> o programa principal (rotas, login, API)
db.py                  -> acesso ao banco de dados (SQLite local / Postgres no Render)
templates/login.html   -> tela de login
templates/index.html   -> tela principal (cadastro e lista de itens)
templates/usuarios.html-> gestão de usuários (só admin)
requirements.txt       -> bibliotecas necessárias
Procfile               -> comando que o Render usa para iniciar o programa
render.yaml             -> modelo de configuração para deploy automático (opcional)
.gitignore              -> arquivos que não devem ir para o GitHub
