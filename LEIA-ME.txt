CONTROLE DE ESTOQUE — ENTRADA E SAÍDA DE EQUIPAMENTO
======================================================

O que é:
Um programa em Python (Flask) com página web, para cadastrar itens:

  - Código do item        - NF de entrada
  - Descrição              - Data de entrada
  - Qtde                   - NF de saída
  - Localização             - Data de saída
  - VD da loja que vai receber o item

Agora o programa tem:
  - LOGIN por usuário e senha (cada pessoa com o seu)
  - Banco de dados de verdade (não é mais um arquivo Excel solto —
    isso é o que permite hospedar na internet sem perder dados)
  - Botão "Exportar para Excel" a qualquer momento, que baixa um
    .xlsx com tudo o que está cadastrado

ACESSO PELO CELULAR
-------------------
O sistema está preparado para celular e inicia ouvindo em 0.0.0.0:5000.

No computador local:
1. Rode normalmente: python app.py
2. O terminal mostra o endereço da rede, por exemplo http://192.168.0.15:5000
3. Conecte o celular na mesma rede Wi-Fi e abra esse endereço no navegador.
4. Dentro do sistema, abra a opção "Celular" do menu para consultar/copiar o endereço.

Se o sistema estiver publicado no Render ou outro servidor HTTPS, abra no celular o mesmo endereço público usado no computador.

Android/Chrome ou Edge: use "Instalar app" / "Adicionar à tela inicial".
iPhone/Safari: Compartilhar > Adicionar à Tela de Início.

Se o acesso local não funcionar, permita o Python/porta 5000 no Firewall do Windows.
